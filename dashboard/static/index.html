Method, provenance & limitations

Five-seed LightGBM (7, 11, 23, 37, 51) blended with zero-shot Chronos-2 for price quantiles. Direction and spike probabilities come from LightGBM. Validation LightGBM weights: 70%, 40%, 50%; test weights: 70%, 40%, 60% for steps 1–4, 5–16, 17–40.

Forecasts are frozen submission outputs. Package input availability and conservative external-data delays are enforced by the forecasting pipeline. Mutations of unavailable future data passed the recorded leakage checks. This dashboard does not retrain or issue live forecasts.

Validation uses the supplied organiser actuals. Test evaluation uses locally reconstructed actuals from the package; the official organiser score remains pending. No raw spot prices are served by this dashboard.

Data: Fingrid, ENTSO-E, licensed Nord Pool inputs, Open-Meteo ECMWF. Models: LightGBM (MIT), Chronos-2 (Apache-2.0). Reference driver exports are from the earlier LightGBM model.
